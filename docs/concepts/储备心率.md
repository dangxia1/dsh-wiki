# 储备心率（Karvonen 指数）

## 定义

把"%VO₂max 强度"换算成"目标心率"的方法。递增运动至力竭时，心率随耗氧量几乎线性增长，但**不是 1:1 换算**——心率有一个"地板"（安静心率），强度百分比描述的是从安静到最大这段**储备量**里的比例。该方法由 Karvonen 于 20 世纪 50 年代中期提出，国内常称**储备心率法**：

$$
\text{目标心率} = \text{安静心率} + (\text{最大心率} - \text{安静心率}) \times k
$$

其中 $k$ 为目标强度（如 0.75 对应 75% VO₂max）。

**例**：安静心率 60 次/分、最大心率 190 次/分、目标 80% VO₂max：

$$
60 + (190 - 60) \times 0.8 = 164 \text{ 次/分}
$$

运动员通过调整速度使心率达到 164 次/分。

## 目标心率计算器

<script setup lang="ts">
import { computed, ref } from 'vue'

const hrMax = ref(190)
const hrRest = ref(60)

const valid = computed(() => hrMax.value > hrRest.value && hrRest.value > 30 && hrMax.value < 230)

const zones = computed(() => {
  const rows: { k: number; hr: number; tag: string }[] = []
  const tags: Record<number, string> = {
    70: '持续训练区间（中央适应）',
    75: '持续训练区间（中央适应）',
    95: '间歇训练区间（外周适应）',
    100: '间歇训练区间（外周适应）',
  }
  for (let k = 50; k <= 100; k += 5) {
    rows.push({
      k,
      hr: Math.round(hrRest.value + (hrMax.value - hrRest.value) * (k / 100)),
      tag: tags[k] || '',
    })
  }
  return rows
})

const recoveryHr = computed(() => Math.round(hrMax.value * 0.6))
</script>

## 要点

### 为什么不能直接用 %最大心率

以 75% VO₂max 运动时，心率**不一定是最大心率的 75%**——必须先减掉安静心率这一段。直接按 %最大心率 设定目标会系统性偏低。

### 三个实操细节

1. **心率稳定有延迟**：以既定强度开始运动后，心率约需 **2～3 分钟**才稳定，开始阶段的读数偏低，不能用来判断强度；
2. **长时间运动心率会上移**：同一摄氧量强度下，随时间延长、体温升高，心率会向上平移——所以应在**训练开始时就按 Karvonen 指数**定好目标，而不是跑后半程再反推；
3. **配速是比心率更稳的参照**：书中明确"用既定速度表述训练强度远比用心率好"，两者可互转——上例运动员以 164 次/分跑步时 400 米约 95 秒内，那"400 米跑进 95 秒"就是更实用的执行标准。

### 恢复期心率：判断"下一组什么时候开始"

- 间歇运动结束时心率应略低于最大心率；
- 恢复期结束时心率应低于 **120 次/分**（20～30 岁运动员）或 **60% 最大心率**（如最大心率 198 对应约 119 次/分——两种表述一致）；
- 随训练进行，若恢复期心率下降变慢，应**延长恢复时间**；若前几组结束时心率已达到最大心率，说明实际强度可能已超过 100% VO₂max，应重新校准速度。

### 最大心率怎么定

- **220 − 年龄**只是粗估，标准差超过 **±10 次/分**，不能作为高水平运动员制定训练计划的依据；
- 实测金标准：实验室递增负荷至疲劳；
- 场地法一：最大速度跑 3 分钟，结束后 **10 秒内**记录的心率即最大心率；
- 场地法二：几次 30 秒全力冲刺、每次间歇 60 秒，通常第三次间歇结束时达到最大心率；
- 手动触诊（桡动脉/颈动脉）：颈动脉按压要轻，过重会反射性减慢心率；运动后心率下降快，10 秒内计数再 ×6，与真实值一般差 1～2 次/分；
- 最大心率在整个训练周期中相对恒定，**每年测 2～3 次**即可。

### 相关的"安静心率"

安静心率 = 任何运动或热身活动之前的心率。长期耐力训练使其下降（心动过缓）：普通人约 70～80 次/分，优秀耐力运动员可低至 **35～40 次/分**——安静心率越低，同样的百分比强度对应的目标心率绝对值越高，这也是必须用储备心率而不是 %最大心率 的原因之一。
